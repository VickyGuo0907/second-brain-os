# Learning Materials

My growing collection of AI engineering resources, learning notes,
and practical experiments.

This section connects what I read with what I build. Each resource
page starts with a reference and expands as I study, test ideas,
and apply them to projects.

## Reading List

- [AI Agents in Depth](ai-agents-in-depth.md)
- [Claude Code from Source](claude-code-from-source.md)
- [Understanding AI Infrastructure](ai-infrastructure.md)

## Suggested Learning Path

1. **AI Agents in Depth** — develop a foundation in agent design,
   context engineering, memory, tools, and evaluation.
2. **Claude Code from Source** — examine a concrete coding-agent
   architecture and identify patterns to test.
3. **Understanding AI Infrastructure** — explore the performance,
   hardware, and system constraints behind AI applications.

Read these in parallel when a project raises a specific question.

## How I Use This Section

“Reviewed” records a reading milestone; notes may continue to evolve.
